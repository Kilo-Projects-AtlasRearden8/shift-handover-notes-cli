# Shift Handover Notes CLI

A local-first Python CLI that converts bullet-style shift notes into plain-language
handover summaries for healthcare workers. Built by **Asdale Dynamics, LLC**.

## Purpose

This tool helps practicing nurses and other healthcare workers turn quick,
bullet-style shift notes into clean, plain-language handover summaries. It is
designed for **education and communication practice only** — it is **not**
medical advice, and it never replaces clinical judgment.

Every summary printed by this tool carries an education-only disclaimer so it
can never be mistaken for a clinical directive.

## Features

- **Bullet-to-plain-language conversion** — strips dash/asterisk/bullet markers,
  capitalizes, and ensures clean sentence punctuation
- **Category-organized summaries** — groups notes by shift category (Meds,
  Vitals, Events, etc.)
- **Local JSON storage** — all records are saved to a local JSON file; nothing
  leaves your machine
- **Printable output** — box-drawn, terminal-friendly summaries you can print
  or copy into a handover sheet
- **Education-only disclaimer** — appears on every summary, every time
- **CLI commands** — `summarize`, `convert`, `list`, `view`, `delete`, `version`
- **Zero dependencies on external APIs** — fully offline, no keys, no accounts


## Usage

### Convert bullets to a plain-language summary (no storage)

```bash
shift-handover summarize -c Meds "gave lisinopril 10mg" "patient tolerated well"
```

### Convert and save to a shift record

```bash
shift-handover convert -c Meds -s SHIFT-001 -u "Floor 3" -d 2026-10-30 \
  "gave lisinopril 10mg" "patient tolerated well"
```

### List all stored shift records

```bash
shift-handover list
```

### View a stored shift record summary

```bash
shift-handover view SHIFT-001
```

### Delete a stored shift record

```bash
shift-handover delete SHIFT-001 --yes
```

### Show version

```bash
shift-handover shift-handover version
# or
python -m shift_handover version
```
